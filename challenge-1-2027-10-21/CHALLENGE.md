# Anagarams

**Level: `EASY`**

**Source: [Kata06: Anagrams](http://codekata.com/kata/kata06-anagrams/)**

[`word_list.txt`](data/word_list.txt) contains a list of words, some of which are anagrams.

Your challenge this week is to fill out the anagaram_challenge function which should return the following: 
- The number of anagramsin the list
- A list of the longest words that are anagrams 
- A list of the most common words that are anagrams 

Feel free to write tests for your code but if you want a quick check, you can run: 

```shell 
uv run main.py 
``` 

which will print out your result and get a performance benchmark of your function. 

**NOTE** watch out for the encoding of the `word_list.txt` file

Good luck!!!
