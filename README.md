# HFU Coding Kata Challenges

Little challenges for the team to do to flex those coding muscles 

Each week I will put the challenge in the challenge folder, and your task is to simply solve the task!
You'll have a bout 30 minutes or so to do it before we review the results.


5 points are awarded for completing the task with bonus points for the following: 
- 1 - fewest lines of code 
- 1 - fastest solution 
- 1 - most ingenious solution

This will then be multiplied by the power level:
- `EASY` - x1
- `MEDIUM` - x1.5
- `HARD` - x2

I will provide a project setup in pythonusing `uv` but you are welcome to use any programming language of your choice.

**Remember, you are not allowed to use AI for this challenge! This is exercises for your brain 🧠**
